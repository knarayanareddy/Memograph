# Memograph review

## Scope and verdict

Memograph is an implementation in beta, reviewed at pinned SHA `9cc5632d570ccda17f8eba038415a670456ae635`. The repository contains substantial Python and TypeScript code, but this is a static sample, not a complete audit or a production certification. **Runtime NOT RUN.** The failed documentation workflow and exposure model need owner attention before release. See [remediation plan](REMEDIATION_PLAN.md).

## Architecture and product boundary

The [README:5–13](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/README.md#L5-L13) says “SQLite is the source of truth” and Markdown/JSON are generated views. The Python module delegates to the [CLI main](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/__main__.py#L3-L5); the [API module](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/__main__.py#L1-L3) has a separate entry. The [TypeScript index](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/sdk/typescript/src/index.ts#L1-L4) exports remote client and local-store modules; the latter is a separate persistence boundary, not merely a wrapper over the Python server. Optional FastAPI dependencies, provider egress, local files, GitHub Pages, PyPI and npm each need separate verification.

## Findings ledger

- **M-01 — Medium; historical CI; high confidence in outcome, unknown cause.** The [Docs run](https://github.com/knarayanareddy/Memograph/actions/runs/41643182480) failed at the pinned SHA. The [workflow:37–46](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/.github/workflows/docs.yml#L37-L46) includes “Build site” and Pages deployment. Logs were not inspected; do not infer which step failed or that current Pages is broken. Inspect logs, reproduce and fix the identified cause.
- **M-02 — Medium; unverified deployment risk; high confidence in documented limitation.** [SECURITY.md:3–6](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/SECURITY.md#L3-L6) states “do not use it as an authorization boundary.” [API settings:31–35](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/settings.py#L31-L35) describe a shared secret. A valid key is not evidence of per-user or per-tenant authorization. Keep deployment private and single-trust-domain, or design and test isolation before shared use.
- **M-03 — Low; confirmed static; high confidence.** [Release workflow:14–26](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/.github/workflows/release.yml#L14-L26) uses action references including `pypa/gh-action-pypi-publish@release/v1`, not immutable commit SHAs. A changed upstream tag could alter privileged release execution; this is not evidence of compromise. Pin reviewed commits and protect publisher environments.
- **M-04 — Medium; confirmed static; high confidence in control flow, deployment impact unverified.** [API app:106–126](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L106-L126) rejects an invalid key at `if fingerprint is None` before `limiter.acquire(client_id)`; [WebSocket:275–283](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L275-L283) does likewise. Thus this application limiter does not throttle failed credential attempts. An upstream control may exist but was not inspected. Add an appropriate pre-auth edge limit and verify both transports without logging credentials.
- **M-05 — Medium; confirmed static; high confidence in scope, operational impact conditional.** [RateLimiter:1–17](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/rate_limit.py#L1-L17) calls itself “in-process” and keeps hits in an instance dictionary. [Auth:10–14, 29–35](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/auth.py#L10-L35) derives a fingerprint from the configured key and returns it after verification; [app:106–126](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L106-L126) passes that identity to the limiter. Separate workers therefore do not share counters; authenticated clients sharing the configured key also share its fingerprint-based budget within a process. Document this limit or enforce a deployment-wide quota, and test the chosen topology.

## Five-discipline assessment

**Correctness/code review.** The API lifespan [initializes and closes](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L70-L80) one manager; `remember`, `recall`, `forget` and `dream` delegate to it. This establishes the visible path, not atomicity or retrieval correctness. Test crash recovery, concurrent consolidation and database-to-view reconciliation against synthetic facts. The TypeScript local store may have different failure behavior and needs its own inspection.

**Automation/testing.** [CI:15–30](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/.github/workflows/ci.yml#L15-L30) uses Python 3.11–3.13, a frozen lock and `pytest` excluding integration tests. The [CI run](https://github.com/knarayanareddy/Memograph/actions/runs/41643182673) succeeded historically at the pinned SHA; it is not a test run by this reviewer. The [SDK manifest:23–28](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/sdk/typescript/package.json#L23-L28) defines its own build and tests. Neither result proves real-provider integration or restore behavior.

**DevOps/operations.** [API settings:47–51](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/settings.py#L47-L51) default the data path to `.memograph` and host to `0.0.0.0`; actual deployment exposure is unknown. The [health route](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L145-L148) calls itself a liveness probe, not a database readiness check. Restore SQLite consistently, verify regenerated views and measure recovery rather than relying on a backup job's success status. Docs and release workflows have distinct permissions and failure modes.

**OWASP/security.** [Auth:21–35](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/auth.py#L21-L35) accepts header or bearer keys and uses `secrets.compare_digest`; [app:97–103](https://github.com/knarayanareddy/Memograph/blob/9cc5632d570ccda17f8eba038415a670456ae635/src/memograph/api/app.py#L97-L103) configures CORS only when origins are supplied. These controls do not prove authorization, safe logs or transport security. SECURITY.md describes prompt, path and SQL injection mitigations, but the implementation was not sampled for those claims. Verify with adversarial transcript, topic and query inputs. Inspect secret handling and retention across provider requests, transcripts, SQLite, exports and backups. Python and npm lockfiles exist; their integrity, vulnerability status and transitive advisories were not checked.

**UI/UX/accessibility.** There is no graphical product interface in the sampled entry points. Relevant interfaces are CLI messages, SDK errors, API responses and published documentation. Check missing-key and unavailable-service guidance, whether WebSocket disconnect/reconnect loses events, and keyboard/screen-reader accessibility of the documentation site; none was tested here.

## Production blockers and owner questions

Decide single-user versus multi-tenant scope, trusted network and edge controls; key rotation and TLS termination; provider egress and memory retention; and backup RPO/RTO. Confirm Pages permissions, PyPI OIDC trust, npm token access, release signing/provenance and rollback authority. The failure of the pinned docs run and absence of measured recovery evidence block a production-readiness claim, not necessarily every private experiment.
